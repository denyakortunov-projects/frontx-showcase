# Standard and Compact widget density

Baseline: published FrontX v0.2.2, source `403c2981a040d959e0fa1a1b0c7ea8ce4fd6c1ba`. Owner requested a second height variant about 30–50% shorter with slightly smaller labels while preserving the original.

Implementation: `WidgetFrame` now owns `density=standard|compact` and computes a Compact height at 65% of its selected Standard height. Gallery cards are 340/221 px. M/L/XL are 304/464/624 px Standard and 198/302/406 px Compact. The same data and chart renderer are used in both. The `density` URL parameter connects the gallery, widget detail, compositions and modular sandbox; Back restores the choice. Compact adjusts header/body spacing, chart labels, heatmap controls and table padding. The build table scrolls within its card if needed; the weekly heatmap explanation remains available to assistive technology. No data, palette or light/dark semantics change.

Verification: production build passes. `verify-density.mjs` passes 22 browser checks covering all 18 gallery widgets, both heights, Back, funnel labels in both display modes, token activity controls, Revenue pulse, composition and modular heights and mobile width. Visual screenshots reviewed. Separate browser inspection of every card in all three compact compositions and the default compact modular layout found no outer-card overflow. `density-report.json` records the automated results.
