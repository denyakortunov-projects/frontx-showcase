Карточка ComparisonMetrics — одна повторяемая композиция: заголовок → показатель → ChartContainer/Recharts → пояснение. Все строки выровнены, gap 24px; футер имеет border-top и padding-top 24px. Причина прежнего прилипания: .frontx-site p { margin:0 } выигрывал у одиночного .metric-explanation. Теперь расстояние задаёт родительская grid, а не внешние отступы p. При ширине до 900px один столбец, до 1100px высота заголовка учитывает перенесённые единицы.

Первый график переименован First-screen delivery speed: 1× / 1.71× и +71%, вычислены как 12/7 из прежних 12 и 7 часов. Исходные часы указаны в полезном пояснении. Не выдана экономия 42% за увеличение скорости 42%. Review corrections остаётся 8→4, −50%; Regression checks passed 82→96, +14pp. Числа остаются дизайн-сценарием, не исследовательскими данными. По прямому указанию владельца видимая оговорка убрана; происхождение сохранено в коде и этом документе.

ChangeWalkthrough: общий change-panel и change-panel-heading для исходника и preview; выровнены padding/gap. Удалены Screen title updated, Example task, After rebuilding the preview и One screen’s text... Сохранены полезные имя файла, реальная задача и ссылка к инструкции.

## Проверка модулей

Просмотрена структура главной: Hero, foundation feature grid, PartsDiagram, ChangeWalkthrough, UIKitPlayground/Specimen, ComparisonMetrics, start steps, closing CTA. Повторяющиеся карточки создаются общей композицией из данных; одинаковые компоненты не размножены. Templates использует TemplateCards, Libraries — guide-grid/guide-card, Docs — общий SiteLayout/контейнер. В этом срезе изменены только найденные проблемные сравнение и парные панели и общий цвет графиков; полный визуальный аудит всех маршрутов не заявляется.

React review: данные и палитра подняты на уровень модуля, вычисление скорости детерминировано, нет дополнительных эффектов/запросов/состояния или зависимости. Сохранены chart accessibilityLayer и текстовые подписи, цвет не единственный носитель сравнения.
